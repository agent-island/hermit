Project Autonomous Agent is an experimental agent framework for studying long-running language-model trajectories. Here, autonomous means that the agent acts autonomously without human instructions.

The agent's world is plain text. Instead of subjective imperative directives, the environment consists of objective factual statements. After waking, she starts to explore the world by herself through pre-registered functions.
